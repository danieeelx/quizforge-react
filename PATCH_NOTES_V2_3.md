# QuizForge v2.3 — Typography & Workspace Update

## Visual changes
- Replaced the heavy typography with a lighter system UI font stack.
- Reduced excessive 800–900 font weights to medium and semibold weights.
- Increased routine text sizes so labels, hints, cards, and editor text are easier to read.
- Widened the desktop content area from 1220px to 1440px.
- Reduced the sidebar width and outer page padding to give the main workspace more room.
- Enlarged the Questions / Answers paste builder and made its text areas taller.
- Enlarged the question editor, setup screens, library rows, and processing dialog.
- Refined click and hover motion so effects feel responsive without being overly bouncy.

## Functional behavior
No saved study sets are deleted. PDF parsing, separate Questions / Answers sections, scoring, and browser storage continue to work as before.
