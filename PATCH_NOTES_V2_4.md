# QuizForge v2.4

## Import confidence
- Added a full import-preview screen before a study set is saved.
- Shows detected count, prepared count, answer coverage, warnings, and blocking issues.
- Detects missing answers, blank choices, duplicate choices, duplicate questions, suspicious choice counts, and invalid answer keys.
- Questions can be included/excluded, searched, filtered, edited, assigned a topic, and given a correct answer directly from the preview.

## Bulk question editing
- Search questions by wording or topic.
- Filter by verification status and topic.
- Select all visible questions or choose individual questions.
- Bulk-delete, mark for review, check verification, and assign topics.
- Added quick A–H answer-key controls to the question list.

## Automatic recovery
- Paste sections, separate answers, title, OCR setting, and AI setting save automatically.
- The dashboard offers to resume an interrupted exam.
- Responses, flags, question position, settings, and timer are recovered.
- The timer accounts for time spent away from the page.

## OCR and image input
- Added scanned-PDF OCR fallback.
- Added PNG, JPEG, and WebP reviewer uploads.
- OCR is used automatically on pages with little selectable text when enabled.
- The processing screen reports which page is being read or OCR-scanned.

## Topics and weak areas
- Imported questions receive automatic topic labels.
- Topics can be changed in the import preview or question editor.
- New attempts store per-question topic results.
- Performance now includes topic accuracy and weakest-topic reporting.
- Exam setup can focus on one topic or automatically practice weak areas.

## Exam experience
- Added navigator filters for all, unanswered, incomplete, flagged, and complete questions.
- Multiple-answer questions with too few selections are marked incomplete.
- Added automatic save status.
- Added a final review screen before submission with clickable question numbers and completion totals.

## UI/UX
- Added spacious validation cards, sticky import actions, refined bulk controls, and responsive layouts.
- Kept the lighter typography and wider v2.3 workspace.
