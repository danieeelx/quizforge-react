# QuizForge v2.9

## Typography
- Displays all visible interface copy, questions, answers, inputs, placeholders, and controls in uppercase.
- Uses a lightweight system-first minimalist font stack with Segoe UI Variable Text, Aptos, Inter, SF Pro Text, and Helvetica Neue fallbacks.
- Reduces heavy bold styling and adds restrained tracking for clearer uppercase text.

## Exam UI fixes
- Lifelines now use a neutral surface while available; purple highlighting appears only while the menu is open.
- The lifeline icon follows the same neutral/open behavior.
- Rebuilt timer alignment with a two-row grid so the clock icon and its hand stay centered beside the time and status.
- Added a compact mobile timer alignment rule.
