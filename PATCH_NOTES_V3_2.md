# QuizForge v3.2

## Manual builder cleanup

- Removed the duplicate **Create Study Set** button from the permanent sidebar.
- A new manual study set no longer creates an empty **Untitled Question 1** card automatically.
- The manual builder now starts with a single, minimal **Add Question** action.
- Clicking **Add Question** creates and opens the first question.
- Removing the last manual question returns the builder to the clean empty state instead of generating another blank card.
- Old completely blank browser drafts are discarded automatically, while partially completed drafts are preserved.
- Corrected the manual-question trash button alignment on desktop and mobile.
