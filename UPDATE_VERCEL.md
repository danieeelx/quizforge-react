# Update QuizForge on Vercel to v3.3

1. Extract `quizforge-vercel-update-v3.3.zip`.
2. Open the existing QuizForge GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload everything from inside the extracted update folder to the repository root.
5. Commit with `Update QuizForge to v3.3`.
6. Wait for Vercel to redeploy.
7. Refresh the live site with `Ctrl + Shift + R`.

Do not delete the repository first. Existing browser study sets and saved progress remain intact.
